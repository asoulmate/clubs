# 화면별 텍스트 와이어프레임 (모바일 기준)

PC(768px 이상)에서는 상단 내비게이션으로 전환되고, 순위표에 득점/실점/득실차/참가율 컬럼이 추가된다.

## 1. 로그인 (#/login)

```text
┌──────────────────────────┐
│          🎾              │
│     모닝스타 테니스        │
│        로그인            │
│ ┌──────────────────────┐ │
│ │ 이메일               │ │
│ ├──────────────────────┤ │
│ │ 비밀번호             │ │
│ └──────────────────────┘ │
│ [       로그인        ]  │
│ 비밀번호 찾기 | 회원가입  │
└──────────────────────────┘
```

회원가입(#/signup): 이메일 / 비밀번호 / 이름 / 입상 구분(선택) 입력.

## 2. 오늘의 경기 (#/) — 메인

```text
┌──────────────────────────┐
│ ‹  7월 24일 (금) ▾  ›     │  ← 이전/달력/다음/오늘
├──────────────────────────┤
│ ┌──────────────────────┐ │
│ │ #1  [⏳ 확정 대기]    │ │
│ │  A팀        B팀      │ │
│ │ [김철수]   [박영희]   │ │  ← 이름 클릭 → 요약 시트
│ │ [이민수]   [+빈 자리] │ │  ← 빈 슬롯 클릭 → 등록
│ │   6    VS    4       │ │
│ │ [스코어 수정][최종 확인]│ │
│ └──────────────────────┘ │
│ ┌──────────────────────┐ │
│ │ #2  [👥 모집 중] ...  │ │
│ └──────────────────────┘ │
│        [+ 경기 만들기]    │  ← 플로팅 버튼
├──────────────────────────┤
│ 🎾오늘 🏆집계 📈기록 ⚙️설정│  ← 하단 고정 내비 (Safe Area)
└──────────────────────────┘
```

## 3. 경기 만들기 (하단 시트)

```text
┌──────────────────────────┐
│ 신규 경기 만들기        × │
│ 7월 24일 · 나는 A팀 1번   │
│ A팀 2번(파트너): [+선택]  │  ← 이름 검색 자동완성
│ B팀 1번:        [+선택]  │     (입상 구분 함께 표시)
│ B팀 2번:        [+선택]  │
│ [      경기 만들기     ]  │  ← 미선택 자리는 빈 슬롯
└──────────────────────────┘
```

## 4. 스코어 입력 (하단 시트)

```text

│   A팀          B팀       │
│ ┌──────┐  :  ┌──────┐   │
│ │  6   │     │  4   │   │  ← 큰 숫자 입력 (inputmode=numeric)
│ └──────┘     └──────┘   │
│ ⓘ 상대 팀 확인 후 확정됩니다│
│ [      확정 요청       ]  │

```

## 8. 관리자 (#/admin)

```text
┌──────────────────────────┐
│ [사용자|경기|수정 이력|설정]│
│ (사용자 탭)               │
│ 🔍 이름 검색              │
│ 김철수  [권한▾] [비활성화] │
│ (경기 탭)                 │
│ #1 확정 A팀.. 6:4 B팀..   │
│ [스코어 수정][참가자 변경]  │
│ [초기화][취소]             │  ← 사유 입력 필수 → 감사 로그
│ (수정 이력 탭)             │
│ 관리자 스코어 수정 · 7/24  │
│ 처리자: 홍길동  6:4 → 6:3 │
│ 사유: 점수 오기입 정정     │
└──────────────────────────┘
```

## 사용자 동선 요약

1. **경기 생성**: 오늘의 경기 → [+ 경기 만들기] → 파트너/상대 선택(생략 가능) → 생성 → 모든 접속자 화면에 실시간 표시
2. **슬롯 참가**: 카드의 [+ 빈 자리] → [나를 이 자리에 등록] 또는 회원 검색 대리 등록
3. **스코어 확정**: 참가자 [스코어 입력] → 확정 요청 → 상대 팀 카드에 [최종 확인] 표시 → 확인 → 확정
4. **통계**: 결과 집계 → 기간 선택 → 이름 클릭 → 요약 → 상세 기록
5. **관리자**: 관리자 탭에서 사용자/경기/이력/설정 관리 (수정 사유는 감사 로그에 기록)
