# 테스트 체크리스트

준비물: 서로 다른 브라우저(또는 시크릿 창) 2개 이상, 테스트 계정 최소 5개(일반 4명 + 관리자 1명).

## 1. 인증

- [ ] 회원가입: 이메일/비밀번호/이름/입상 구분 입력 → 가입 → `profiles` 행 자동 생성 확인
- [ ] 이메일 인증이 켜진 경우: 인증 전 로그인 시 한글 안내 메시지 표시
- [ ] 잘못된 비밀번호 로그인 → "이메일 또는 비밀번호가 올바르지 않습니다."
- [ ] 로그인 후 새로고침 → 세션 유지 (로그인 상태 유지)
- [ ] 비밀번호 재설정 메일 발송 → 메일 링크(#/update-password) → 새 비밀번호로 로그인
- [ ] 로그아웃 → 로그인 화면으로 이동

## 2. 경기 개설·참가자 편성

- [ ] 경기 생성 시 생성자가 A팀 1번으로 자동 등록
- [ ] 참가자를 선택하지 않고 생성 → 빈 슬롯 3개 표시
- [ ] 이름 일부 검색 → 자동완성, 입상 구분 표시, 동명이인 구분 가능
- [ ] 비활성 사용자는 검색 결과에서 제외
- [ ] 이미 편성된 사용자는 검색 결과에서 제외 (양 팀 중복 등록 차단)
- [ ] 다른 계정으로 빈 슬롯에 "나를 등록" → 성공
- [ ] 두 브라우저에서 동시에 같은 빈 슬롯 등록 → 한쪽만 성공, 다른 쪽 "이미 다른 사용자가 해당 자리에 등록되었습니다."
- [ ] 4명 편성 완료 → 상태가 자동으로 `편성 완료(ready)`로 변경
- [ ] 참가자 1명 제외 → 상태가 자동으로 `모집 중(open)`으로 복귀
- [ ] 일반 사용자가 남이 등록한 슬롯 제거 시도 → 제거 버튼 없음 (API 직접 호출 시 한글 오류)
- [ ] 대리 등록 설정 OFF 시 일반 사용자의 대리 등록 차단

## 3. 스코어 입력·확정 (양측 확정 모드)

- [ ] 참가자가 아닌 계정 → 스코어 입력 버튼 미표시 (API 직접 호출 시 "경기 참가자만 스코어를 입력할 수 있습니다.")
- [ ] 참가자 4명 미만 경기에 스코어 입력(API) → "참가자 4명이 모두 등록된 후..." 오류
- [ ] 음수/최대 점수 초과 입력 → 한글 오류
- [ ] 동점 입력(동점 불허 설정) → "동점은 허용되지 않습니다..."
- [ ] 참가자 A 확정 요청 → 상태 `확정 대기`, 같은 팀에는 [최종 확인] 미표시
- [ ] 상대 팀 참가자에게만 [최종 확인] 표시 → 확인 → 상태 `확정`
- [ ] 확정 후 일반 참가자에게 수정 버튼 미표시 (API 호출 시 "확정된 경기는 관리자만 수정할 수 있습니다.")
- [ ] 확정 대기 중 다른 참가자가 스코어 재제출 → 확인 기록 리셋, 다시 상대 팀 확인 필요
- [ ] 두 브라우저에서 동시에 스코어 제출 → 한쪽 "다른 사용자가 방금 이 경기를 수정했습니다..." (낙관적 잠금)
- [ ] 단일 확정 모드로 변경 후 제출 → 즉시 확정
- [ ] 취소된 경기에 스코어 입력(API) → 한글 오류

## 4. 실시간 공유

- [ ] 브라우저 2개로 같은 날짜를 열고: 경기 생성 → 다른 브라우저에 새로고침 없이 카드 추가
- [ ] 참가자 등록/제외 → 실시간 반영
- [ ] 스코어 제출/확정/취소 → 실시간 반영
- [ ] 네트워크 끊었다 복구(개발자도구 오프라인) → 재연결 후 목록 자동 최신화

## 5. 집계·순위

- [ ] 확정 경기만 집계 포함 (확정 대기/취소 경기는 제외)
- [ ] 일간/주간(월~일)/월간/분기/연간/누적 전환 시 기간 라벨과 수치 정확
- [ ] 승률 = 승/경기 × 100, 0경기 사용자는 0%
- [ ] 참가율: 같은 날 2경기 참가해도 참가 1일로 계산
- [ ] 동률 사용자 공동 순위(1, 2, 2, 4위) 표시
- [ ] 최소 경기 수 설정 시 미달 사용자 "제외" 표시로 하단 배치
- [ ] 이름 클릭 → 요약(누적 경기/승/패/승률) → 상세 기록 보기 → 개인 상세 페이지
- [ ] 개인 상세: 파트너별 승패·승률, 월별 추이, 최근 경기 정확성

## 6. 관리자

- [ ] 일반 사용자에게 관리자 메뉴 미표시, #/admin 직접 접근 시 메인으로 이동
- [ ] 일반 사용자 계정으로 admin RPC 직접 호출(브라우저 콘솔) → 한글 권한 오류
- [ ] 서브 관리자: 확정 스코어 수정(사유 필수), 초기화, 취소, 참가자 변경, 사용자 비활성화 가능
- [ ] 서브 관리자: 역할 변경 불가 / 시스템 설정 변경 불가 (조회만)
- [ ] 관리자: 역할 변경 가능 (자기 자신 제외), 시스템 설정 변경 가능
- [ ] 확정 스코어 수정 시 사유 미입력 → 저장 불가
- [ ] 수정 이력 탭에 처리자/시각/변경 전후 점수/사유 표시
- [ ] 비활성화된 사용자로 로그인 → "비활성화된 계정" 안내 화면

## 7. 날짜·시간대

- [ ] 브라우저 시간대를 미국 등으로 변경해도 "오늘"이 한국 날짜로 표시
- [ ] 한국 시간 자정 전후 경기 생성 → 올바른 날짜에 저장
- [ ] 날짜 이동(이전/오늘/다음/달력 선택) 정상 동작

## 8. 모바일 UI

- [ ] iPhone/Galaxy 실기기 또는 개발자도구 시뮬레이션에서 375px 폭 레이아웃 확인
- [ ] 가로 스크롤 없음, 본문 글자 16px 이상, 터치 영역 44px 이상
- [ ] 스코어 입력 시 숫자 키패드 표시, 입력창 포커스 시 화면 확대로 깨지지 않음
- [ ] 하단 내비게이션이 홈 인디케이터(Safe Area)와 겹치지 않음
- [ ] 이름 클릭 요약이 모바일에서 하단 시트로 표시
- [ ] 상태가 색상+아이콘+텍스트로 함께 구분됨

## 9. 예외·네트워크

- [ ] 오프라인 상태에서 저장 → "서버 저장에 실패했습니다. 네트워크 상태를 확인한 후 다시 시도해주세요."
- [ ] 뒤로 가기 후 재진입 시 최신 데이터 로드
- [ ] 잘못된 개인 상세 주소(#/players/없는id) → "사용자를 찾을 수 없습니다."
